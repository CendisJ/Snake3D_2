# Snake Infinite (Android)

Native Android game written in Java (no HTML/WebView).

## Build APK

The included GitHub Actions workflow builds `app-debug.apk` automatically after pushing this project to GitHub. Open **Actions** → **Build Snake Infinite APK** → latest successful run → **Artifacts** → `SnakeInfinite-APK`.

Controls: drag the joystick in the lower-left, or touch/drag the play area to steer. The snake's head remains centered while the infinite grid scrolls underneath it. Collect glowing food orbs.
